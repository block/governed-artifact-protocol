# Core record schemas

Use [`core.schema.json`](core.schema.json) to check the shape of a GAP record. It contains the record definitions and their shared pieces in JSON Schema draft 2020-12.

The schema checks fields and types. The [specification text](../README.md#concepts) defines the rules and the [read and verify](../README.md#6-read-and-verify) checks for digests, record references, and signatures.
